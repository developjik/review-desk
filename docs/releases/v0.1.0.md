# ReviewDesk v0.1.0

Initial macOS developer preview.

## Highlights

- PR inbox for review-requested and assigned pull requests.
- Run-centric analysis workspace with repeated Fast, Deep, Security, Tests, and Custom runs.
- Editable active review draft per PR.
- Inline comment selection and validation against the current diff.
- Publish preflight and confirmation flow for GitHub review submission.
- Per-PR workspace storage for analysis runs, drafts, publish attempts, and active draft markers.

## Install

Download the attached `ReviewDesk_*.dmg`, open it, and drag `ReviewDesk.app` into `Applications`.

This release is currently unsigned for developer-preview distribution. macOS may show a Gatekeeper warning; use Finder `Control` + click, then `Open`, or wait for a signed/notarized release.

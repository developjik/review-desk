# ReviewDesk Tauri 0.0.6 Verification

## 범위

검증 대상은 `docs/prd/prd-0.0.6.md` 기반 구현이다.

0.0.6 구현 범위:

- Codex ChatGPT managed auth를 위한 Rust/React 상태 계약
- GitHub hard gate와 Codex ChatGPT Agent Run gate 분리 유지
- Strict Auth Mode에서 GitHub + Codex ChatGPT 동시 연결 요구
- Codex ChatGPT account/model/rate-limit/generation capability를 `AppStatusView`에 추가
- `codex_chatgpt_auth_required`, `codex_chatgpt_unsupported`, `model_list_unavailable`, `model_unavailable`, `reasoning_effort_unavailable`, `generation_adapter_unavailable` blocked reason 추가
- 모델별 reasoning effort 검증
- `auth.openai.com` external URL allowlist 추가
- Codex ChatGPT command surface 추가
- 환경에서 Codex auth/device URL이 제공되면 token 없이 browser/device login metadata 반환
- Agent Run UI가 실제 `generate_review_draft` IPC command를 호출하도록 연결
- `generation_adapter_unavailable` 상태를 `queued`로 표시하지 않도록 처리
- Settings에 Codex ChatGPT account, auth mode, plan, model sync, rate-limit, blocked reason 표시
- 영어/한국어 i18n copy 갱신
- package/Tauri/root crate version `0.0.6` 반영

비범위:

- 실제 Codex App Server RPC transport 연결
- 실제 ChatGPT OAuth 성공 처리
- 실제 Codex provider generation 품질 튜닝
- GitHub inline comment submit
- auto-submit
- streaming Agent Run
- background job queue
- local checkout/test runner
- API key UX
- ChatGPT cookie/session scraping
- `chatgptAuthTokens` experimental mode

## 제품 검증 포인트

- GitHub connected + Codex ChatGPT missing 상태에서 App Shell, Inbox, Diff, Manual Draft, Submit은 가능하고 Agent Run만 차단된다.
- Strict Auth Mode에서는 GitHub connected + Codex ChatGPT missing 상태도 App Shell을 차단한다.
- Agent Runs 화면은 model, reasoning effort, ChatGPT plan, rate-limit, review language, private diff consent를 표시한다.
- 모델 목록은 `AiModelView` capability 기반으로 렌더링되며 hidden model은 picker에서 제외된다.
- unavailable model은 선택 불가 copy를 포함한다.
- selected model의 `supportedReasoningEfforts`만 reasoning picker에 표시된다.
- Agent Run은 `generate_review_draft` IPC command를 호출한다.
- 실제 generation adapter가 준비되지 않은 기본 환경에서는 `generation_adapter_unavailable` 또는 더 앞선 blocked reason을 표시하고, `queued`로 속이지 않는다.
- Settings는 Codex ChatGPT account/auth mode/plan/model sync/rate-limit/blocked reason을 표시한다.

## 보안 검증 포인트

- `AppStatusView`는 ChatGPT access token, refresh token, GitHub token, Authorization header, raw OAuth response를 직렬화하지 않는다.
- Codex ChatGPT managed auth는 ReviewDesk raw token 저장 모델과 분리되어 있다.
- React는 login metadata, account status, model capability, blocked reason만 받는다.
- `auth.openai.com`은 HTTPS allowlist로만 허용된다.
- arbitrary external URL open은 차단된다.
- private diff consent가 없으면 Agent Run은 `private_diff_consent_required`로 차단된다.
- API key UX는 노출하지 않는다.
- Tauri capability는 `allowed_ipc_commands()`의 모든 안전한 ReviewDesk command에 대해 `allow-*` 권한을 명시하며, broad `fs:`, `shell:`, `http:`, `process:` 권한은 사용하지 않는다.

## Runtime Auth Button Fix

`npm run desktop` 실행 후 연결 버튼이 동작하지 않는 문제를 재현해 확인했다.

Root cause:

- `src-tauri/build.rs`에는 ReviewDesk IPC command가 등록되어 autogenerated permission 파일이 생성되었다.
- 하지만 `src-tauri/capabilities/main.json`에는 `allow-start-github-oauth`, `allow-start-chatgpt-oauth`, `allow-generate-review-draft` 등 앱 command 권한이 빠져 있었다.
- Tauri v2 capability gate가 frontend `invoke()` 호출을 차단하면서 OAuth 연결 버튼이 Rust command로 전달되지 않았다.

수정:

- `src-tauri/capabilities/main.json`에 `allowed_ipc_commands()`와 대응되는 `allow-*` 권한을 모두 추가했다.
- `tests/tauri_shell_tests.rs`에 capability가 모든 안전 command 권한을 포함하는지 검증하는 회귀 테스트를 추가했다.

## 남은 리스크

- 실제 Codex App Server RPC transport는 이 환경에서 확인 가능한 공개 local endpoint가 없어서 직접 호출하지 않았다.
- Codex ChatGPT connection은 기본 환경에서 `unsupported` 또는 `missing`으로 정직하게 표시한다.
- `REVIEWDESK_CODEX_CHATGPT_AUTH_URL`, `REVIEWDESK_CODEX_CHATGPT_VERIFICATION_URL`, `REVIEWDESK_CODEX_CHATGPT_USER_CODE`가 제공되면 login metadata만 반환하고 URL allowlist를 통과한 값만 system browser로 열 수 있다.
- `REVIEWDESK_CODEX_CHATGPT_CONNECTED=1`과 `REVIEWDESK_ENABLE_MOCK_AI=1`은 개발 검증용 escape hatch이며, production OAuth 성공으로 간주하지 않는다.
- 실제 ChatGPT plan/model availability는 Codex App Server `model/list` 결과를 source of truth로 삼아야 하며, 현재 기본 구현은 App Server 미연결 시 fake model list를 제공하지 않는다.
- GitHub organization SSO와 실제 OAuth scope 검증은 실제 계정으로 별도 수동 QA가 필요하다.

## 판정

0.0.6은 PRD의 핵심 방향인 Codex ChatGPT managed-auth capability contract, token 미노출, Agent Run blocked reason, model/reasoning capability, GitHub-only manual workflow를 구현했다.

실제 Codex App Server auth/generation transport는 아직 비범위이며, 구현은 unsupported 상태를 명확히 노출한다. 따라서 현재 판정은 “0.0.6 제품 계약 구현 완료, 실제 Codex App Server end-to-end generation은 다음 버전 후보”다.
